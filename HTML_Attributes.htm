1. HTML Attributes

HTML attributes provide additional information about HTML elements. They are always specified in the start tag and usually come in name/value pairs like name="value".

Some common HTML attributes include:

1. id - Specifies a unique id for an element

2. class - Specifies one or more class names for an element (used for styling)

3. style - Specifies an inline CSS style for an element

4. title - Specifies extra information about an element (displayed as a tooltip)

5. href - Specifies the URL of a link (used in <a> tags)

6. src - Specifies the URL of an image (used in < ;img> tags)

7. alt - Specifies alternative text for an image (used in <img> tags)

8. width - Specifies the width of an element (used in <img> and <video> tags)

9. height - Specifies the height of an element (used in <img> and <video> tags)

10. type - Specifies the type of an element (used in <input> and <button> tags)

11. value - Specifies the value of an element (used in <input> and <option> tags)

12. name - Specifies the name of an element (used in <input> and <form> tags)

13. placeholder - Specifies a short hint that describes the expected value of an input field (used in <input> and <textarea> tags)

14. disabled - Specifies that an element should be disabled (used in <input>, <button>, and <select> tags)

15. checked - Specifies that an input element should be pre-selected when the page loads (used in <input type="checkbox"> and <input type="radio"> tags)

16. readonly - Specifies that an input field is read-only (used in <input> and <textarea> tags)

17. required - Specifies that an input field must be filled out before submitting the form (used in <input>, <select>, and <textarea> tags)

18. autofocus - Specifies that an input field should automatically get focus when the page loads (used in <input> and <textarea> tags)

19. multiple - Specifies that a user can enter more than one value (used in <input type="file"> and <select> tags)

20. data-* - Used to store custom data private to the page or application (used in any HTML element)

21. lang - Specifies the language of the element's content (used in any HTML element)

22. dir - Specifies the text direction for the content in an element (used in any HTML element)

23. tabindex - Specifies the tab order of an element (used in any HTML element)

24. accesskey - Specifies a shortcut key to activate/focus an element (used in any HTML element)

25. contenteditable - Specifies whether the content of an element is editable or not (used in any HTML element)

26. draggable - Specifies whether an element is draggable or not (used in any HTML element)

27. hidden - Specifies that an element is not yet, or is no longer, relevant (used in any HTML element)

28. spellcheck - Specifies whether the element is to have its spelling and grammar checked or not (used in any HTML element)

29. translate - Specifies whether the content of an element should be translated or not (used in any HTML element)

30. role - Specifies the role of an element (used in any HTML element)

31. aria-* - Specifies accessibility information for an element (used in any HTML element)

32. title - Specifies extra information about an element (displayed as a tooltip)

33. onclick - Specifies a JavaScript function to run when the element is clicked (used in any HTML element)

34. onmouseover - Specifies a JavaScript function to run when the mouse pointer is moved onto the element (used in any HTML element)

35. onmouseout - Specifies a JavaScript function to run when the mouse pointer is moved out of the element (used in any HTML element)

36. onkeydown - Specifies a JavaScript function to run when a key is pressed down (used in any HTML element)

37. onkeyup - Specifies a JavaScript function to run when a key is released (used in any HTML element)

38. onload - Specifies a JavaScript function to run when the page has finished loading (used in the <body> tag)

39. onunload - Specifies a JavaScript function to run when the page is unloaded (used in the <body> tag)

40. onsubmit - Specifies a JavaScript function to run when a form is submitted (used in the <form> tag)

41. onreset - Specifies a JavaScript function to run when a form is reset (used in the <form> tag)

42. onfocus - Specifies a JavaScript function to run when an element gets focus (used in any HTML element)

43. onblur - Specifies a JavaScript function to run when an element loses focus (used in any HTML element)

44. oninput - Specifies a JavaScript function to run when the value of an element is changed (used in any HTML element)

45. onchange - Specifies a JavaScript function to run when the value of an element is changed (used in any HTML element)

46. ondrag - Specifies a JavaScript function to run when an element is being dragged (used in any HTML element)

47. ondrop - Specifies a JavaScript function to run when an element is dropped (used in any HTML element)

48. onscroll - Specifies a JavaScript function to run when an element is scrolled (used in any HTML element)

49. onresize - Specifies a JavaScript function to run when the window is resized (used in the <body> tag)

50. onerror - Specifies a JavaScript function to run when an error occurs while loading an element (used in any HTML element)

51. oncontextmenu - Specifies a JavaScript function to run when the right mouse button is clicked (used in any HTML element)

52. onwheel - Specifies a JavaScript function to run when the mouse wheel is rolled up or down over an element (used in any HTML element)

53. oncopy - Specifies a JavaScript function to run when the content of an element is copied (used in any HTML element)

54. oncut - Specifies a JavaScript function to run when the content of an element is cut (used in any HTML element)

55. onpaste - Specifies a JavaScript function to run when the content of an element is pasted (used in any HTML element)

56. onselect - Specifies a JavaScript function to run when the content of an element is selected (used in any HTML element)

57. ondragstart - Specifies a JavaScript function to run when the user starts to drag an element (used in any HTML element)

58. ondragend - Specifies a JavaScript function to run when the user has finished dragging an element (used in any HTML element)

59. ondragenter - Specifies a JavaScript function to run when the dragged element enters a valid drop target (used in any HTML element)

60. ondragleave - Specifies a JavaScript function to run when the dragged element leaves a valid drop target (used in any HTML element)

61. ondragover - Specifies a JavaScript function to run when the dragged element is over a valid drop target (used in any HTML element)
