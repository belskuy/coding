<q> and <blockquote> Tags

Monday, November 2nd, 2026

1. <q> Tag

The <q> tag is used to define a short inline quotation. The text inside the <q> element is usually displayed in quotation marks by default.

Example:

This is a short quotation.

2. <blockquote> Tag

The <blockquote> tag is used to define a long quotation. The text inside the <blockquote> element is usually displayed as an indented block of text.

Example:

Berbicaralah dari hati, yang terdengar lembut, sederhana dan jujur.

Orang-orang akan memahami dan menyukai kita.
