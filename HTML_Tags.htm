1. HTML Tags

An HTML tag is a keyword enclosed in angle brackets. An HTML tag normally comes in pairs like <h1> and </h1>. The first tag in a pair is the start tag, the second tag is the end tag (they are also called opening tags and closing tags). The end tag has a forward slash before the tag name. The text between the start and end tags is the content of the element.

some HTML tags are self-closing and do not have an end tag. For example, <br> is a self-closing tag that defines a line break.

Lists of self-closing tags in html:

1. <area> - Defines an area inside an image map

2. <base> - Defines a base URL for all relative URLs in a document

3. <br> - Defines a single line break

4. <col> - Specifies column properties for each column within a <colgroup> element

5. <embed> - Defines a container for an external application or interactive content (a plug-in)

6. <hr> - Defines a thematic change in the content

7. <img> - Defines an image

8. <input> - Defines an input control

9. <link> - Defines the relationship between a document and an external resource (most used to link to stylesheets)

10. <meta> - Defines metadata about an HTML document

11. <source> - Defines multiple media resources for media elements (<video> and <audio>)

12. <track> - Defines text tracks for media elements (<video> and <audio>)

13. <wbr> - Defines a possible line-break

14. <command> - Defines a command that the user can invoke

15. <keygen> - Defines a key-pair generator field (for forms)

16. <param> - Defines a parameter for an object
